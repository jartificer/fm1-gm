Playing it

This is the firmware itself, compiled to WebAssembly from the same sources as the device build: the screens, the sequencer, the 128 GM sounds and the drum kit. Songs you save stay in this browser's flash.

KnobsDrag up and down, scroll, or focus one and use the arrow keys
KeysZ…/ is F3 to A4 with the black keys on the row above, W…U goes on to G5
PLAYSpace
HoldHold a button with the mouse as long as the manual says: SEL twice for a new song, ARP for 1 s to erase a track

The panel's button order is an approximation of the real FM-1. The manual is in the README.

Install on your FM-1

Connect the FM-1 with a USB data cable, then let this page use MIDI. Chrome, Edge and Opera on a computer can do this; Safari cannot.
